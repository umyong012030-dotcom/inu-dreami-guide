선택한 파일은 이 페이지에서 서버로 업로드하지 않습니다.
교육자료는 이 사이트에 포함되어 있지 않습니다.

처음 이용하시나요?

  1. 교육자료 파일 받기

    담당자가 별도로 전달한 HTML 파일을 내 기기에 저장하세요. ZIP으로 받았다면 압축을 먼저 풀어 주세요.

  2. 파일 선택하기

    ‘내 기기에서 HTML 선택’을 누르고 저장한 파일을 선택하세요.

  3. 새 탭에서 학습하기

    파일 이름을 확인한 뒤 ‘새 탭에서 자료 열기’를 누르세요. 담당자에게 받은 신뢰할 수 있는 파일만 여세요.

파일을 아직 받지 못했다면

교육 담당자에게 최신 HTML 파일을 요청해 주세요. 이 사이트에서는 교육자료를 다운로드할 수 없습니다.

열리지 않거나 기록을 이어 쓰려면

받은 HTML 파일을 Chrome·Edge 등의 브라우저로 직접 열어 사용하세요. 이 페이지를 닫거나 새로고침하면 파일을 다시 선택해야 합니다.
